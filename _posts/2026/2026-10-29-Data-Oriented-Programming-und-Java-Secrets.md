## Zusammenfassung

### Datenorientierte Programmierung mit Java

**{{ page.speaker[0].name }}**

Data Oriented Programming (DOP) ist ein aufkommendes Paradigma, das die Art und Weise verändert, wie wir in Java Daten modellieren und verarbeiten: Daten und Verhalten werden voneinander getrennt. Dieser Vortrag stellt die zentralen Prinzipien von DOP vor: Daten unveränderlich und transparent modellieren, an Systemgrenzen validieren, ungültige Zustände durch das Datenmodell ausschließen und Operationen von Datenstrukturen trennen.

Mit modernen Java-Sprachmitteln wie Records, Sealed Classes und Pattern Matching bietet DOP für viele Anwendungen eine einfachere und besser wartbare Alternative zur klassischen objektorientierten Programmierung (OOP). Anhand praktischer Beispiele erfährst du, wie DOP die Lesbarkeit, Testbarkeit und Erweiterbarkeit von Code verbessert und wann du dich für DOP oder OOP entscheiden solltest.

Du lernst, wie du die neuesten Möglichkeiten von Java nutzt, um klarere, sicherere und robustere Anwendungen zu entwickeln, in denen Daten als Daten im Mittelpunkt stehen.

### Speed Dating Java Secrets

**{{ page.speaker[1].name }}**

Eine Folie Theorie, dann lauffähiger Code. Das ist das Format dieses Vortrags. Er zeigt eine Reihe kleiner Beispiele von Java-Features, die wenig bis nicht bekannt sind. Warum kennen wir sie nicht?

- Weil sie für die eigenen Entwicklungsarbeiten nicht relevant sind.
- Weil sie eventuell relevant sind, es aber nie in die bekannten Blogs geschafft haben.
- Weil sie recht schräg und damit wenig sinnvoll einsetzbar sind.
- Weil sie ein Implementierungsdetail ohne sichtbare Auswirkungen sind.
- Und eventuell noch einige andere Gründe mehr …

Dieser Vortrag reiht Java-Geheimnisse, manchmal auch einfach nur Kuriositäten, in loser Folge aneinander. Du willst etwas Neues erfahren, auch wenn du es wahrscheinlich nie einsetzen wirst? Dann bist du hier richtig. Details können wir jetzt nicht verraten, sonst wäre es ja kein Geheimnis mehr. Du musst die Katze im Sack kaufen.

Nach dem Vortrag kennst du ein paar neue Features und Eigenheiten der Java-Plattform. In der Regel für den täglichen Einsatz wenig geeignet, aber Spaß gemacht hat es trotzdem und informativ war es auch.
